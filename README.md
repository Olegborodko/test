# Сайт (в разработке)

Статический сайт, который пишется с нуля в этом репозитории.
Правила разработки и конвенции кода — в `AGENTS.md`.

## Статус

Скелет проекта. Тематика, структура страниц и контент ещё не утверждены — см. «Открытые вопросы».

## Что известно

- Сайт делается с нуля, без готовых шаблонов.
- Технологии: чистые HTML + CSS + JS, без сборки и зависимостей.
- Владелец проверяет результат с телефона (Android), поэтому приоритет — мобильный вид.
- Исходники хранятся в GitHub-репозитории `Olegborodko/test`.

## Структура

```
index.html             главная страница
assets/css/style.css   стили
assets/js/main.js      скрипты
assets/img/            картинки и иконки
AGENTS.md              правила для ИИ-агентов
```

## Как запустить локально

Открыть `index.html` в браузере — этого достаточно. Или поднять статический сервер:

```bash
python3 -m http.server 3000
```

## Открытые вопросы

Пока не решено — нужно от владельца:

1. **Тема и назначение сайта.** Что это: визитка, лендинг продукта, портфолио, блог, что-то ещё?
2. **Кому он адресован и какое действие должен вызывать** (позвонить, купить, подписаться, просто прочитать).
3. **Набор страниц.** Предложение по умолчанию: одна страница с секциями; отдельные страницы —
   только если понадобятся.
4. **Контент.** Тексты, заголовки, контакты, ссылки — что есть готовое, что писать мне.
5. **Визуальный стиль.** Есть ли референсы, фирменные цвета, логотип; или выбираю я.
6. **Язык.** По умолчанию русский.
7. **Домен и хостинг.** Нужен ли отдельный домен; где публиковать, когда будет готово.

## Журнал решений

- **Стек — чистая статика.** Не тянем фреймворк и сборку, пока задача не потребует.
  Причина: сайт небольшой, мгновенный предпросмотр с телефона, нет зависимостей и сборки.
- **Mobile-first.** Базовый CSS — под узкий экран, расширения через `min-width`.
- **Контент и стиль** — после ответов на вопросы выше.
